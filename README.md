# Dust-Running
🌅 Dust Run is a lightweight HTML5 Canvas endless runner where you ride through a desert sunset, dodge obstacles, jump across gaps, and challenge yourself to achieve the highest distance.

---

# ✨ Features

Dust Run delivers a lightweight yet engaging endless runner experience with modern web technologies.

- 🏍️ Fast-paced endless runner gameplay
- 🌅 Beautiful animated desert sunset environment
- 🎨 Smooth HTML5 Canvas rendering
- ⚡ Progressive difficulty and speed scaling
- 🪨 Procedurally generated obstacles
- ⬆️ Variable-height jump mechanics
- 📏 Real-time distance tracking
- 🏆 Persistent high-score system using Local Storage
- 📱 Mobile-friendly touch controls
- ⌨️ Keyboard support for desktop
- 📐 Responsive design for multiple screen sizes
- 🚀 Zero dependencies — runs directly in the browser

# 🐞 Known Issues

The current release is stable, but a few improvements are planned.

- Minor collision inconsistencies at very high speeds.
- Audio system has not yet been implemented.
- High scores are stored locally and do not sync across devices.
- Refreshing the page resets the current game session.
- Mobile gameplay is best experienced in landscape orientation.
